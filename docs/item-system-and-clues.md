## 1. 概述

本文档定义Demo章节中所有物品的属性分类、交互逻辑，以及**线索系统**的详细设计。

### 1.1 物品分类体系

| 大类 | 子类 | 说明 | 示例 |
|------|------|------|------|
| **场景物件** | 纯查看 | 只可查看/阅读，不可拾取 | 日记本、密码箱 |
| | 可收纳 | 可拾取进物品栏 | 旧抽屉钥匙、钢笔 |
| | 一次性操作 | 互动后改变状态，不产生物品 | 抽屉（打开后保持打开） |
| **线索物品** | 含文本 | 上面有文字信息，首次弹纸条，后自动归档 | 生日贺卡、发票、儿子卡片、泛黄贺卡 |
| **收藏品** | 无文本 | 仅作为情感收藏，不放入线索系统 | 崭新英雄钢笔 |
| **工具** | 可交互 | 在物品栏中可与其他物品/场景产生交互 | 旧抽屉钥匙（开锁）、钢笔（触发特殊反馈） |

### 1.2 交互逻辑关键词

| 关键词 | 含义 |
|--------|------|
| **点击** | 在场景中点击物品 |
| **拾取** | 物品从场景移入物品栏 |
| **使用(物品→场景)** | 从物品栏拖拽物品到场景目标 |
| **使用(物品→物品)** | 从物品栏拖拽物品到另一个物品栏物品 |
| **翻看** | 点击查看文本内容（弹出/放大） |
| **归档** | 首次翻看后自动存入线索系统 |
| **锁定** | 物品当前不可互动，满足条件后解锁 |

## 3. 线索系统（Clue System）

### 3.1 系统概述

| 属性 | 值 |
|------|-----|
| **系统名称** | 线索系统（Clue System） |
| **入口** | 物品栏的一个**子页签** |
| **功能** | 收纳玩家已发现的所有含文本物品，供随时回顾 |

| **最大容量** | 本Demo上限10条（实际4条） |

### 3.3 页签设计

| 页签 | 标签 | 图标 | 默认 | 说明 |
|------|------|------|------|------|
| 📦 物品 | "物品" | 背包图标 | ✅ 默认选中 | 显示所有可收纳物品 |
| 📜 线索 | "线索" | 卷轴图标 | ❌ | 显示所有已归档线索条目 |

**页签切换**：点击页签文字/图标切换，或按 **Q/E** 键左右切换页签。

### 3.4 线索条目详情

| 属性 | 值 |
|------|-----|
| **条目显示** | 缩略模式：图标+标题+摘要（一行）+日期 |
| **点击条目** | 弹出**全文查看模式**——纸条/卡片放大，显示全部文本 |
| **排序** | 按获取时间倒序（最新的在最上面） |
| **日期格式** | 物品上的历史日期（如"1977.09"）或发现日期 |

### 3.5 线索获取流程

```
【第一次与场景中含文本物品互动】
    │
    ▼
1. 点击场景中的线索物品（如：生日贺卡）
    │
    ▼
2. 放大动画：物品在屏幕中央以"纸条浮出"效果展示
    │
    ▼
3. 文字逐行显现（打字机效果，0.5s/行）
    │
    ▼
4. 玩家阅读完毕后，点击"关闭"按钮或点击画面空白处
    │
    ▼
5. 关闭后自动触发：
   ├── 物品缩小动画 → 飞入右下角物品栏方向
   ├── 物品栏按钮出现微光脉冲提示（新线索！）
   └── 线索系统新增条目
    │
    ▼
6. 玩家可在任意时刻打开物品栏→切换到"线索"页签→查看已归档的线索
```

### 8.3 ItemObject 组件设计

```csharp
public enum ItemCategory
{
    SceneObject,    // 场景物件·纯查看
    SceneContainer, // 场景容器
    PickupTool,     // 工具·可收纳
    PickupCollect,  // 收藏品·可收纳
    ClueItem        // 线索物品·含文本
}

public class ItemObject : MonoBehaviour
{
    public string itemId;
    public ItemCategory category;
    public bool isStorable;
    public bool hasClueContent;     // 是否含线索文本
    public string clueTitle;        // 线索标题
    [TextArea] public string clueText; // 线索全文
    
    // 状态
    public bool isPickedUp;         // 已被拾取
    public bool isClueArchived;     // 已被归档
    public bool isInteractable;     // 当前是否可互动
    
    // 交互
    public void OnClick();          // 点击处理
    public void OnDragToItem(string targetItemId); // 拖拽到物品
    public void OnDragToScene(string targetObjId); // 拖拽到场景物件
}
```

### 8.4 存档数据

[System.Serializable]
public class ItemSaveData

    public SerializableDictionary<string, bool> sceneItemStates; // 场景物品状态
