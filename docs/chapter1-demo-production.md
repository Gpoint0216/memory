## 1. 概述

### 1.1 设计目标

本Demo为参赛用可玩章节，选取完整游戏第一章的核心情感线浓缩为**一个完整关卡**（约8-15分钟流程），展示游戏核心玩法与情感体验：

- 核心玩法：双时空切换、物品探索、碎片拼合、钢笔解锁日记
- 情感核心：老人通过旧物找回被遗忘的爱人的名字
- 技术验证：场景切换、时空切换、物品系统、日记系统、动画演出

### 1.2 剧情概要

```
1977年秋，张志明在供销社买了一对英雄钢笔，
一支送给暗恋的同桌刘玉珍作为生日礼物，另一支留给自己。

他把送给玉珍的礼物放在一个密码箱里，密码是玉珍的阳历生日。
几十年后，老人阿尔兹海默症加重，连玉珍的名字都已忘记。

儿子送来一支新钢笔，希望帮父亲找回记忆。
老人通过寻找贺卡、钥匙、发票、日历等旧物线索，
一步步找回密码，打开尘封的密码箱——

最终记起那个名字：刘玉珍。
```

### 1.3 关卡数据总览

| 项目 | 数值 |
|------|------|
| 场景数 | 2个（少年卧室、客厅） |
| 双时空场景数 | 2个（卧室有现在/过去两套状态，客厅有现在/过去两套状态） |
| 可互动物品总数 | 10件 |
| 日记隐藏关键词 | 10个（按解锁顺序逐步显现） |
| 小游戏 | 1个（钥匙转动对齐） |
| 密码谜题 | 1个（0921阳历生日推算） |

| 预计通关时长 | 8-15分钟 |

## 2. 开场动画（演出详细脚本）

### 2.1 分镜脚本

| 镜号 | 时长 | 画面描述 | 音效/音乐 | 字幕 |
|------|------|---------|-----------|------|
| 1 | 0-3s | **黑屏渐亮**，淡入到一间昏暗的老旧卧室。晨光从窗帘缝隙透入，照在书桌上。灰尘在光线中缓慢飘浮。 | 环境音：寂静，远处隐约有钟声。BGM：轻柔钢琴单音渐入 | 无 |
| 2 | 3-6s | **镜头缓推**（极慢），从卧室全景推向书桌上一本破旧的日记本。日记本封面皮面脱落，纸张泛黄。 | 钢琴音渐强，加入一个温暖的和弦 | 无 |
| 3 | 6-9s | **一只苍老的手**（只拍手和日记本）从画面外缓缓伸入画面，手指颤抖着抚摸日记本封面。手背上可见老人斑。 | 布料摩擦声，老人的呼吸声（轻缓） | 无 |
| 4 | 9-13s | **手翻开日记本**，内页一片模糊，字迹像被水洇过一样无法辨认。日记本纸张泛黄卷边。 | 纸张翻动声，音乐停顿一拍 | 无 |
| 5 | 13-17s | **切到老人面孔特写**（首次揭示主角）。老人（64岁）面容沧桑，眼神迷茫。他眉头微皱，嘴唇翕动。 | 呼吸声，音乐微弱持续 | 无 |
| 6 | 17-21s | 老人**声音（VO，苍老、缓慢、带着茫然）**： "这是我写的日记吗……字迹都看不清了……" | VO入，音乐淡至几乎无声 | 无 |
| 7 | 21-25s | 镜头**缓慢拉远**，老人坐在书桌前，手按着日记本。窗外的光照在他的侧脸上。他环顾四周，眼神陌生。 | VO继续： "我的记忆……怎么也想不起来……陌生又熟悉……" | 无 |
| 8 | 25-28s | 老人低下头，VO： "我到底……身在何处……" | VO结束，留白2秒 | 无 |
| 9 | 28-32s | **全黑**1秒，然后游戏标题浮现： | 一声清脆的**风铃声**（时空切换音效的变体） | 《记忆碎片》 **第一章** |

**总时长：约32秒**

### 2.2 技术实现要点

| 元素 | 实现方式 |
|------|---------|
| 镜头缓推 | Cinemachine Virtual Camera，dolly轨道，极慢速度 |
| 灰尘粒子 | 粒子系统，微小半透明圆形，随机飘动 |
| 老人手部 | 3D/2D手部动画，需关键帧抖动表现老人颤抖 |
| 老人面孔 | 2D立绘或3D模型，需表现眼神迷茫和微表情 |
| VO对白 | 配音演员录制，音色需苍老、缓慢、略带沙哑 |
| 标题浮现 | 文字淡入+金色粒子散开效果 |

## 4. 关卡流程详细设计（逐步骤拆解）

### 4.1 步骤1：探索日记本

#### 4.1.1 流程

| 子步骤 | 操作 | 系统反馈 |
|-------|------|---------|
| 1.1 | 开场动画结束后，画面切到**卧室·现代**。老人坐在书桌前，桌上放着一本破旧日记本。 | 画面稳定，环境音（寂静、风声） |
| 1.2 | 玩家**点击日记本** | 日记本放大动画（翻开），显示**日记首页——全部字迹模糊，无法辨认** |
| 1.3 | 自动触发老人**VO独白** | 详见4.1.2 |
| 1.4 | VO结束后，日记本页面抖动一下，浮现**一行模糊但可辨认的手写字**："1977 年秋 七月廿九 晴"（仅日期可见，正文全模糊） | 日期文字是日记本唯一可见的内容 |
| 1.5 | 玩家**点击"关闭"** 或**点击画面空白处** | 日记本合上，恢复到卧室场景 |

#### 4.1.2 对话/独白详情

| 说话者 | 文字内容 | 音频提示 | 触发方式 |
|-------|---------|---------|---------|
| 老人（VO，迷茫） | "这是我写的日记吗……字迹都看不清了……" | 配音+字幕 | 翻开日记时自动播放 |
| 老人（VO，缓慢） | "我的记忆……怎么也想不起来……陌生又熟悉……" | 配音+字幕 | 上一句结束后0.5s自动播放 |
| 老人（VO，低声） | "我到底……身在何处……" | 配音+字幕 | 上一句结束后0.5s自动播放 |

#### 4.1.3 美术需求

| 资源 | 描述 | 尺寸 |
|------|------|------|
| diary_cover_closed | 日记本封面（破旧皮面） | 400x550 |
| diary_page_blurred | 日记内页（字迹完全模糊，仅日期可见） | 900x540 |
| diary_ink_blur | 模糊墨迹纹理叠加层 | 900x540 |

#### 4.1.4 关键词解锁

**本步骤无关键词解锁**——首次进入仅展示日记本的初始模糊状态。

### 4.2 步骤2：发现生日贺卡

#### 4.2.1 流程

| 子步骤 | 操作 | 系统反馈 |
|-------|------|---------|
| 2.1 | 关闭日记本后，画面上**书桌**区域有**微光闪烁提示**（可互动物品的标准提示效果） | 物品微光循环闪烁 |
| 2.2 | 玩家**点击书桌上的生日贺卡** | 贺卡**放大动画**（如从信封中抽出） |

| 2.5 | **日记图标闪烁**（右上角日记按钮发光），提示日记有更新 | 日记按钮发光+UI提示 |
| 2.6 | 玩家**点击日记按钮** → 打开日记 → **"生日""礼物""抽屉"三个关键词解锁** → 日记页面对应位置从`■■`变为文字 | 金色微光+叮声（详见3.4） |

#### 4.2.2 对话/独白详情

| 说话者 | 内容 | 情绪 |

| 文字 | "父亲，生日快乐，礼物放在抽屉里了" |

| 参数 | 值 |
|------|-----|
| 名称 | 钥匙转动对齐 |
| 类型 | 角度旋转匹配 |
| 难度 | ★☆☆☆☆（引导式教学） |
| 时长 | 5-15秒（玩家操作） |

#### 4.6.3 玩法说明

```
┌─────────────────────────────────────┐
│                                     │
│   【钥匙插入锁孔】                   │
│                                     │
│         ┌───────────────┐           │
│         │  ████████████ │           │
│         │  ██  钥匙  ██ │           │
│         │  ████████████ │           │
│         │     ▲         │           │
│         │     │         │           │
│         │   锁孔        │           │
│         │               │           │
│         │  ◀ 旋转 ▶     │           │
│         │               │           │
│         │  [←→] 对齐    │           │
│         │  [ENTER] 确认 │          │
│         │               │           │
│         └───────────────┘           │
│                                     │
│   提示：旋转钥匙到正确的角度        │
│        让钥匙齿与锁孔对齐            │
│                                     │
└─────────────────────────────────────┘
```

**操作方法**：玩家使用**鼠标拖拽旋转**或**左右方向键**旋转钥匙，当钥匙齿与锁孔对齐时，按**回车/空格**或**点击"确认"按钮**完成。

**成功**：钥匙转动顺畅 → `click` 声 → 抽屉打开
**失败**（角度不对）：钥匙发出"咔"的卡顿声 → 轻微抖动 → 可以继续尝试（无惩罚）

**防卡关**：旋转时钥匙边缘与锁孔边缘有**对齐提示**——当角度接近正确值（±15°范围内）时，钥匙**发出微弱的金色光芒**，提示玩家"接近了"。

#### 4.6.4 成功后的反馈

| 子步骤 | 操作 | 反馈 |
|-------|------|------|
| 6.1 | 钥匙对齐成功 | 开锁声 → 抽屉自动滑开的动画 |
| 6.2 | 抽屉打开 | 特写：抽屉内有一个**礼物盒** |

## 8. Unity实现要点

### 8.1 场景管理

| 场景 | 文件名 | 备注 |
|------|--------|------|
| 卧室·现代+过去 | Scene_Bedroom | 同一场景，两套Layer/GameObject |
| 客厅·现代+过去 | Scene_Livingroom | 同上 |

每个场景包含**当前+过去**两套视觉状态，通过 **TimeSpaceManager.cs** 的 `SetTimeSpace(bool isPast)` 切换。

### 8.2 物品管理

| 组件 | 功能 |
|------|------|
| InteractiveObject.cs | 所有互动物品：点击→放大→交互 |
| ItemPickup.cs | 可拾取物品：添加到Inventory |
| TimeSpaceAware.cs | 每个物品在现在/过去的两套Sprite/状态 |
| UnlockCondition.cs | 解锁条件（某关键词解锁后→该物品变为可互动） |

### 8.3 对话系统

| 组件 | 功能 |
|------|------|
| DialogueTrigger.cs | 触发VO+字幕 |
| DialogueData.cs | ScriptableObject：文本+音频+字幕时长 |

### 8.4 日记系统

| 组件 | 功能 |
|------|------|
| DiaryController.cs | 日记UI + 关键词解锁管理 |
| KeywordData.cs | ScriptableObject：10个关键词+解锁条件 |

### 8.5 小游戏

| 组件 | 功能 |
|------|------|
| KeyAlignMinigame.cs | 钥匙旋转对齐小游戏 |
