## 1. 概述

### 1.1 章节数据总览

| 项目 | 数值 |
|------|------|
| 关卡数 | 3关（1-1, 1-2, 1-3） |
| 场景数 | 4个（少年卧室、家门口小巷、老旧阳台、客厅） |
| 双时空场景数 | 4个（每个场景有现在/过去两套状态） |
| 可互动物品总数 | 14件 |
| 意象对总数 | 6对 |
| 核心道具 | 钢笔（全章唯一钥匙） |
| 日记页解锁数 | 3页 |
| 预计通关时长 | 20-35分钟 |
| 对话/独白行数 | 约45行 |
| 动画演出数 | 4段（3关结束动画 + 1章结束动画） |

### 1.2 玩家体验流程

```
开始 → 关卡1-1: 被抹去的名字（~8-12min）
         → 记起"刘玉珍"这个名字
       ↓
       关卡1-2: 消失的同桌（~6-10min）
         → 记起"她是我的同桌"
       ↓
       关卡1-3: 不敢说的喜欢（~8-15min）
         → 记起"我喜欢她"
         → 章节高潮：我不是忘了，是不敢记得
       ↓
       章节结束
```

### 1.3 核心机制说明

| 机制 | 说明 | 首次出现 |
|------|------|---------|
| **点击物品** | 点击可互动物品触发检查/拾取 | 1-1 |
| **时空切换** | 在现在/过去两个时空之间切换，场景物品状态变化 | 1-1 |
| **场景切换** | 通过场景地图点击切换不同场景 | 1-1 |
| **物品合并** | 拖拽两个碎片到物品栏合并 | 1-1 |
| **钢笔解锁日记** | 拖拽钢笔到日记本，金光动画解锁日记页 | 1-1 |
| **钢笔+物品互动** | 拖拽钢笔到特定物品触发特殊反馈 | 1-3 |

## 2. 关卡1-1：被抹去的名字

### 2.1 关卡设计

#### 2.1.1 核心数据

| 项目 | 值 |
|------|-----|
| 日记内容 | "开学那天，我捡到了一支钢笔和一张纸条。纸条上写着一个名字——刘玉珍。" |
| 解谜目标 | 找到她的名字"刘玉珍" |
| 场景数 | 3个 |
| 可互动物品数 | 5件 |
| 必须互动的物品 | 3件 |
| 探索自由度 | 高（3条路径均可通关） |

#### 2.1.2 解谜目标拆解

```
最终目标：用钢笔解锁日记第1页
  ├── 子目标1: 获得完整姓名纸条（3种方式）
  │     ├── 方式A: 在过去时空的课本里直接获取
  │     ├── 方式B: 合并现在时空2个碎片获得
  │     └── 方式C: 发现过去时空纸条后直接获取
  └── 子目标2: 发现钢笔刻字（必须在过去时空）
        └── 条件: 切换到卧室-过去时空
```

### 2.2 通关路线完整展开

#### 路线A：先找课本（推荐—最短路线，4步）

```
步骤1：【卧室-现在】点击书桌上的发霉课本
  → 放大动画：课本翻开，残破纸条掉落
  → 老人语音："高一数学...我好像记得这本书..."
  → 获得物品：[残破纸条]（显示"刘..."）

步骤2：【卧室】点击时空切换按钮（1.5秒渐变）
  → 暖光渐亮，课本变为崭新状态
  → 环境音切换：寂静→远处学生声+鸟鸣

步骤3：【卧室-过去】点击课本
  → 翻开动画，完整纸条夹在书中
  → 获得物品：[完整姓名纸条]（显示"刘玉珍，高一(3)班"）
  → 老人语音："刘玉珍...这是...她的名字？"

步骤4：【卧室-过去】点击钢笔，查看刻字
  → 特写镜头：钢笔刻字"玉珍赠，1978秋"
  → 老人语音："玉珍...赠？这是谁送我的..."

步骤5：【卧室-过去】拖拽钢笔到日记本
  → 金光升腾动画（2.5秒）
  → 日记第1页解锁
  → 老人呢喃："刘玉珍...这个名字...我好像...记得..."
  → 触发关卡结束动画
```

#### 路线B：先找碎片（5步）

```
步骤1：【小巷-现在】点击地面缝隙
  → 特写：纸片露出一角
  → 获得物品：[纸条碎片A]（显示"刘..."）

步骤2：【客厅-现在】点击旧书包
  → 放大动画：书包打开，纸片露出
  → 获得物品：[纸条碎片B]（显示"...珍"）

步骤3：【物品栏】拖拽碎片A到碎片B
  → 合并动画（0.5秒），纸张拼合
  → 获得物品：[残破姓名纸条]（显示"刘+...珍"）
  → 老人语音："刘...珍？刘珍？还是..."

步骤4：【卧室-过去】在课本里找到完整纸条对比
  → 获得物品：[完整姓名纸条]

步骤5：【卧室-过去】钢笔解锁日记（同路线A步骤4-5）
```

#### 路线C：先发现钢笔（4步）

```
步骤1：【卧室-现在】点击钢笔
  → 放大动画：钢笔笔尖断裂
  → 老人语音："这支笔...好像是我的...但笔尖断了..."
  → 获得物品：[断裂的钢笔]

步骤2：【卧室-过去】切换时空
  → 点击钢笔，查看刻字
  → 特写镜头："玉珍赠，1978秋"

步骤3：【卧室-过去】在课本里发现完整纸条
  → 获得物品：[完整姓名纸条]

步骤4：【卧室-过去】钢笔解锁日记
```

### 2.3 失败反馈

| 玩家尝试 | 系统反馈 | 意图 |
|---------|---------|------|
| 点击现在时空的模糊纸条 | "看不清...字迹都模糊了..." | 引导切换时空 |
| 用断裂的钢笔解锁日记 | 无反应，老人："笔尖断了...写不出字..." | 引导查看过去时空的钢笔 |
| 没找到纸条直接解锁日记 | "我...想不起她的名字..." | 提示缺少关键信息 |
| 在过去时空点击已拿过的物品 | "这个我已经看过了..." | 防止重复操作 |

### 2.4 防卡关机制

| 时间 | 触发条件 | 反馈 |
|------|---------|------|
| 2分钟无进展 | 计时器 | 老人："这个房间...好像有很多旧东西..." |
| 3分钟无关键操作 | 计时器 | 日记本闪烁微光（视觉提示） |
| 4分钟无关键操作 | 计时器 | 老人："也许...换个时间看看？"（强提示） |
| 5分钟无关键操作 | 计时器 | UI箭头指向时空切换按钮 |

## 3. 关卡1-2：消失的同桌

### 3.1 关卡设计

#### 3.1.1 核心数据

| 项目 | 值 |
|------|-----|
| 日记内容 | "高二分班，她成了我的同桌。她数学很好，经常帮我讲题。她有一块白色碎花手绢，总是用来擦橡皮屑和钢笔屑。" |
| 解谜目标 | 记起玉珍是自己同桌 |
| 场景数 | 3个 |
| 可互动物品数 | 6件 |
| 必须互动的物品 | 3件 |
| 新增机制 | 物品合并、抽屉互动 |

#### 3.1.2 解谜目标拆解

```
最终目标：用钢笔解锁日记第2页
  ├── 子目标1: 获得白色碎花手绢
  │     ├── 方式A: 过去时空直接打开抽屉获取
  │     └── 方式B: 合并现在时空2个碎片
  ├── 子目标2: 发现数学解析纸条上的"玉珍"署名
  │     └── 条件: 必须在过去时空查看
  └── 子目标3: 用钢笔触碰日记本
```

### 3.2 通关路线完整展开

#### 路线A：先找手绢（推荐，4步）

```
步骤1：【卧室-现在】点击书桌抽屉
  → 抽屉卡住动画（轻微抖动+卡顿声）
  → 老人语音："打不开...锁住了..."

步骤2：【卧室-过去】切换时空
  → 抽屉变为可开状态

步骤3：【卧室-过去】点击抽屉
  → 抽屉滑开动画（木质摩擦声）
  → 发现白色碎花手绢，叠整齐
  → 获得物品：[白色碎花手绢]
  → 老人语音："白色碎花...这好像...是谁的手绢..."
  → 拖拽钢笔到手绢：手绢显现淡淡墨迹
  → 老人语音："她用这块手绢擦钢笔屑..."

步骤4：【卧室-过去】翻看数学笔记本
  → 放大动画：笔记本翻开，有清秀字迹
  → 发现解析纸条，署名"玉珍"
  → 老人语音："这字迹...不是我的...是她的...玉珍..."

步骤5：【卧室-过去】钢笔解锁日记
  → 金光动画
  → 日记第2页解锁
  → 老人呢喃："她...是我同桌..."
  → 触发关卡结束动画
```

#### 路线B：先找碎片（5步）

```
步骤1：【客厅-现在】点击椅背校服口袋
  → 发现白色碎花布片
  → 获得物品：[手绢碎片A]

步骤2：【阳台-现在】点击杂物堆
  → 发现另一块白色碎花布片
  → 获得物品：[手绢碎片B]

步骤3：【物品栏】合并碎片A+B
  → 拼合动画
  → 获得物品：[残破手绢]
  → 老人语音："这手绢...好像是谁的..."

步骤4：【卧室-过去】打开抽屉，找到完整手绢对比
  → 确认手绢归属

步骤5：【卧室-过去】钢笔解锁日记
```

### 3.3 失败反馈

| 玩家尝试 | 系统反馈 | 意图 |
|---------|---------|------|
| 在现在时空点击抽屉 | 卡住动画，"打不开..." | 引导时空切换 |
| 没找到手绢就解锁日记 | "我...只记得她的名字...不记得别的了..." | 提示缺少关键信息 |
| 没找到解析纸条就解锁日记 | "她...好像帮过我什么...想不起来..." | 提示缺少信息 |

### 3.4 防卡关机制

| 时间 | 反馈 |
|------|------|
| 2分钟无进展 | 抽屉轻微发光提示 |
| 3分钟无进展 | 老人："那时候...好像有人坐在我旁边..." |
| 5分钟无进展 | UI箭头指向时空切换按钮 |

## 4. 关卡1-3：不敢说的喜欢

### 4.1 关卡设计

#### 4.1.1 核心数据

| 项目 | 值 |
|------|-----|
| 日记内容 | "毕业那天，我捡了很多银杏叶做成书签，用她送的钢笔在上面写下'我喜欢你'。我还写了一封告白信，但我太害怕了，不敢送给她。不是忘了...是不敢记得。" |
| 解谜目标 | 记起自己喜欢过玉珍（章节高潮） |
| 场景数 | 4个 |
| 可互动物品数 | 7件 |
| 必须互动的物品 | 4件 |
| 碎片数 | 4个告白碎片 |
| 特殊互动 | 钢笔+银杏叶写字 |

#### 4.1.2 解谜目标拆解

```
最终目标：用钢笔解锁日记第3页（章节高潮）
  ├── 子目标1: 发现银杏叶书签
  │     ├── 方式A: 过去时空卧室笔记本里获取
  │     └── 方式B: 阳台摘银杏叶+钢笔写字
  ├── 子目标2: 阅读告白纸条完整内容
  │     ├── 方式A: 过去时空笔记本夹层直接获取
  │     └── 方式B: 合并4个碎片后对比
  └── 子目标3: 用钢笔触碰日记本
        └── 触发章节高潮动画
```

### 4.2 通关路线完整展开

#### 路线A：银杏书签优先（推荐—情感体验最佳，5步）

```
步骤1：【卧室-现在】点击笔记本
  → 翻开动画，发现内页有撕痕
  → 老人语音："这里...撕掉了什么...我为什么要撕掉..."

步骤2：【卧室-过去】切换时空
  → 笔记本变为崭新状态

步骤3：【卧室-过去】点击笔记本
  → 翻开动画，发现银杏叶书签
  → 获得物品：[银杏叶书签]
  → 放大特写：书签上写有"毕业快乐，我喜欢你"
  → 老人语音（颤抖）："我喜欢你...这是我写的？"

步骤4：【阳台-过去】点击银杏树
  → 摘取新鲜银杏叶
  → 获得物品：[新鲜银杏叶]
  → 特殊互动：拖拽钢笔到银杏叶
    → 钢笔自动写字动画（笔迹显现）
    → 特写："毕业快乐，我喜欢你"
  → 老人语音："我...用这支笔...在银杏叶上写字..."

步骤5：【卧室-过去】再次点击笔记本
  → 发现夹层有告白纸条
  → 获得物品：[告白纸条（完整）]
  → 放大特写：告白信内容
  → 老人语音（颤音）："我写了告白...写了三年..."

步骤6：【卧室-过去】钢笔解锁日记
  → 金光升腾动画
  → 日记第3页解锁
  → 章节高潮动画触发
```

#### 路线B：碎片拼合（收集向，7步）

```
步骤1：【卧室-现在】地面缝隙 → 告白碎片A
步骤2：【阳台-现在】枯叶堆 → 告白碎片B
步骤3：【小巷-现在】墙角缝隙 → 告白碎片C
步骤4：【客厅-现在】书包夹层 → 告白碎片D
步骤5：【物品栏】合并4个碎片 → [残破告白纸条]
  → 拼合动画，告白内容逐渐显现
  → 老人语音："这是...我写给她的？"
步骤6：【卧室-过去】对比完整告白纸条
步骤7：钢笔解锁日记
```

### 4.3 失败反馈

| 玩家尝试 | 系统反馈 |
|---------|---------|
| 现在时空阅读撕碎告白 | "撕碎了...看不清写了什么..." |
| 没找到银杏书签 | "银杏叶...我好像捡过...用来做什么来着..." |
| 没找到告白纸条就解锁 | "毕业那天...好像发生了什么...但想不起来..." |

### 4.4 防卡关机制

| 时间 | 反馈 |
|------|------|
| 3分钟无进展 | 笔记本闪烁提示 |
| 5分钟无进展 | "毕业那天...好像发生了什么..." |
| 7分钟无进展 | 碎片位置高亮提示 |

## 8. Unity实现要点

### 8.1 场景管理

| 系统 | 说明 |
|------|------|
| **SceneController** | 管理4个场景的加载/卸载，使用Addressables按需加载 |
| 每个场景文件 | 1个Unity场景包含2套视觉层（现在/过去），通过Layer或GameObject.SetActive切换 |
| 场景切换 | 淡入淡出过渡，1秒 |

### 8.2 时空切换系统

| 项目 | 实现方式 |
|------|---------|
| 切换触发 | 点击UI按钮 |
| 视觉过渡 | Image.fillAmount动画+Shader水彩效果（或简单Alpha Lerp） |
| 物品状态 | 每个物品挂载TimeSpaceAware组件，存储现在/过去两套状态 |
| 过渡时长 | 1.5秒 |
| 切换冷却 | 2秒内不能连续切换 |

### 8.3 物品系统

| 组件 | 说明 |
|------|------|
| `InteractiveObject.cs` | 所有可互动物品的基础组件 |
| `ItemData` | ScriptableObject，存储物品ID、名称、描述、图标、大图 |
| `TimeSpaceState` | 现在/过去两套状态（Sprite、碰撞体、描述文本） |
| `FragmentItem` | 碎片物品，合并ID和合并规则 |
| `PenItem` | 钢笔特殊处理，解锁日记逻辑 |

### 8.4 日记系统

| 项目 | 实现方式 |
|------|---------|
| 日记UI | UI Toolkit，右上角四分之一区域 |
| 解锁条件 | 钢笔碰撞检测+已获取必要物品 |
| 解锁动画 | Animator控制，粒子金光效果 |
| 页面数据 | ScriptableObject数组，每页文字+解锁状态 |

### 8.5 动画系统

| 项目 | 实现方式 |
|------|---------|
| 简单物品动画 | Animator + Animation Clip |
| 闪回动画 | Video Player播放预渲染视频 或 Timeline序列帧 |
| 时空切换 | 全屏Image + 材质参数Lerp |
| 对话弹出 | 云朵气泡UI，从上到下展开 |

### 8.6 数据流

```
GameManager (单例)
  ├── SceneManager: 场景加载/卸载
  ├── TimeSpaceManager: 时空状态
  ├── Inventory: 物品栏数据
  ├── DiaryManager: 日记解锁状态
  └── DialogueManager: 对话/独白触发
```

### 8.7 存档数据

```csharp
[System.Serializable]
public class Chapter1SaveData

    public bool level1_1_complete;
```
