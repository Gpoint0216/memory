# 《记忆》游戏项目

## 项目简介

《记忆》是一款叙事解谜 Demo。项目由 5 人团队在约 1 个月内完成，我负责第一章全部关卡与交互设计。

## 项目内容

- 第一章包含 3 个关卡和现实 / 记忆双时空场景
- 点击调查、物品收集、物品合并、拖拽使用
- 场景切换、旋转机关、对话与语音触发
- 多路线解谜、失败反馈和防卡关提示

## 运行方式

双击 `Memento.exe` 启动 Windows Demo。

## 演示视频

仓库内包含 `Memory-Demo-Video.mp4`，使用 Git LFS 管理。

## 个人职责

负责第一章关卡流程、场景状态、物品与线索、机关规则、交互触发、失败反馈和 QA 验收标准。
